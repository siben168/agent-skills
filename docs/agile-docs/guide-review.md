# Guide / Runbook 模板提案

状态：已确认并纳入技能包；本文只保留维护对照依据。

## 对照结论

参考来源项目 `docs/templates/003_guide.md`、GD-013 数据库迁移指南与 GD-007 日志标准。只借鉴结构，不将其中技术栈、环境、命令或审批习惯变成通用要求。

| 参考中的做法 | 提议 |
|---|---|
| 原模板已有目的、前置条件、操作、验证 | 保留；步骤紧邻预期结果，必要时再做整体验证，避免把所有成功判断留到最后 |
| GD-013 明确哪些服务适用、在哪个环境执行、脚本依赖什么假设 | 前置条件写影响正确性的实际条件；命令说明工作目录、环境和参数来源，不让读者猜目标 |
| GD-013 说明“命令成功”与实际操作完成可能不同 | 结果检查关注目标是否达成，不只看退出码或健康端点 |
| GD-013 包含历史故障细节 | 保留能改变操作判断的症状、检查和处理；完整事故过程归复盘，不继续叠加进主流程 |
| GD-007 包含格式规范、实现示例和推广状态 | 既有标准可继续作为权威指南；引用已有契约，推广任务归台账，不强行把所有 Guide 改成步骤表 |
| 原模板没有明确失败时是否继续或怎样恢复 | 对有状态变更补充停止条件、恢复办法和限制；只读或低影响指南不机械增加回滚章节 |
| 原模板重复通用维护规则 | 维护规则留在 skill / 项目约定，具体指南只写适用条件与必要事实 |
