# 研究材料与归档提案

状态：已确认并纳入技能包；本文只保留维护对照依据。

## 对照结论

参考来源项目 `004_tmp_research.md`、归档入口、ADR-040 的研究归档和 PRD-099 的历史研究快照。

| 现有做法 | 建议 |
|---|---|
| 研究记录区分问题、方法、证据与结论 | 保留必要信息，不要求每次调查都创建文件 |
| 发现使用 High / Medium / Low 可信度 | 优先写已证实、推断、未验证及适用限制；没有依据的置信度标签帮助有限 |
| 后续处理有多种采纳去向的勾选框 | 只记实际去向；不要产生一份隐藏的执行任务表 |
| 归档顶部说明原因，并链接当前文档 | 保留；不另做归档文档类型或完整模板 |
| 历史研究与已确认设计分开 | 保留历史证据，采纳的规则进入正式权威文档，不让两份内容并行演进 |
